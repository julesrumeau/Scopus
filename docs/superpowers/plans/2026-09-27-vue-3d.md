# La 3D de la vue — plan (étape 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre l'onglet 3D en vue normale. En y passant, on voit en nuage de points la zone affichée sur la carte, à partir des points déjà téléchargés, sous un plafond réglable et avec un ombrage de profondeur (EDL). Le nuage reste figé en 3D et n'est reconstruit que si la carte a bougé.

**Architecture:**
- Le worker du relief garde aussi l'intensité des points et rend un nuage échantillonné sur l'emprise (`nuage3d`) ainsi que le drapé d'une couche (`drape3d`).
- Le fil principal le pose dans la `Vue3D` existante, qui gagne une passe EDL.
- Tout le reste de la 3D est réutilisé tel quel : gestes, boussole, couleurs, classes, sélection, mesure, lien.

**Tech Stack:** scripts classiques, WebGL2, worker monté depuis une URL blob, tests `node --test`, parcours Playwright dans le Chromium de WSL.

**Spec:** `docs/superpowers/specs/2026-09-27-vue-3d-design.md`

## Global Constraints

- Ouverture en `file://` :
  - scripts classiques, **aucun `import`** ;
  - tout identifiant lu par `app.js` existe dans `index.html` (`test/sources.test.js`) ;
  - **pas de backtick dans un commentaire GLSL** (`shaders.js`).
- Tout ce qui part dans le worker est une fabrique `function fabriqueX()` ou une fonction listée dans `relief-travailleur.js` : elle ne ferme que sur les globaux du worker.
- Coordonnées ramenées à une origine locale **avant** la conversion en `Float32`.
- La vue 3D est rendue **à la demande** (`invalider()`) ; toute nouvelle méthode qui change l'affichage l'appelle.
- Aucune requête réseau pour la 3D.
- Le calcul lourd reste dans le worker, au processeur. La carte graphique ne sert que pour le dessin, sur le fil principal, et pour les couches SVF déjà en place.

## Review Focus

- **Emprise vide ou sans bloc** : réponse `vide` et avis « Zoomez », sans erreur (tâches 1, 4).
- **Points exactement sur le bord de l'emprise** : gardés d'un côté seulement, pour que deux vues voisines n'aient pas de doublon au rendu (tâche 1).
- **Retour en 3D sans avoir bougé** : même nuage, aucun recalcul ni voile ; après un déplacement, l'ancien nuage est libéré avant le nouveau (tâche 4).
- **Moteur tout-GPU (`&gpu`)** : les points n'y restent pas en mémoire ; `nuage3d` rend `vide` avec une raison, et l'avis le dit (tâches 1, 4).
- **Redimensionnement du canevas avec l'EDL** : ses textures suivent la taille ; aucune image noire (tâche 3).

### Task 1: Le nuage de la vue, dans le worker

**Files:**
- Modify: `src/vue-relief.js` (`creer` : `nuage3d`)
- Modify: `src/relief-travailleur.js` (intensité transférée ; demande `nuage3d` ; `surFilPrincipal.nuage3d`)
- Test: `test/vue-relief.test.js`, `test/relief-travailleur.test.js`

**Interfaces:**
- Produces:
  - `moteurVue.nuage3d(emprise, budget, actifs?) → null | { raison } | nuage`, avec :
    - `nuage = { n, x, y, z: Float32Array, cls: Uint8Array, intensite: Uint16Array, hauteur: Float32Array, origine: [xmin, ymin, zRefM], emprise, zmin, zmax, parClasse: Array<[cls, n]> }` ;
    - `x, y, z` relatifs à `origine`, en mètres ;
    - `zmin, zmax` : bornes des `z` relatifs ;
    - `hauteur` : `z` moins l'altitude du sol, lue dans la dernière surface calculée ; 0 hors de la surface.
  - Un point est gardé si `xmin ≤ x < xmax` et `ymin ≤ y < ymax` (en centimètres absolus), et si `hacher(xc, yc, zc) < budget / total`.
  - Le worker reçoit `{ type: 'nuage3d', id, emprise, budget, actifs }` et répond `{ type: 'nuage3d', id, …nuage }`, ou `{ …, vide: true, raison }`. Tous les tableaux sont transférés.
  - `RELIEF_TRAVAILLEUR.creer().nuage3d(emprise, budget, actifs) → Promise<nuage | null>`. `null` avec `.raison` si vide : l'objet rendu vaut `{ vide: true, raison }`.
  - `ajouter(bloc)` côté fil principal transfère aussi `p.intensite` si elle existe.

Dans `creer` de `vue-relief.js` :

```js
    // Hachage entier d'un point (centimètres absolus) → [0, 1) : le tirage du
    // plafond est déterministe — même vue, mêmes points, pas de scintillement
    // d'un passage en 3D à l'autre — et sans état.
    function hacher(x, y, z) {
      let h = Math.imul(x ^ 0x9e3779b9, 0x85ebca6b) ^ Math.imul(y ^ 0xc2b2ae35, 0x27d4eb2f) ^ Math.imul(z, 0x165667b1);
      h ^= h >>> 15; h = Math.imul(h, 0x2c1b3c6d); h ^= h >>> 12; h = Math.imul(h, 0x297a2d39); h ^= h >>> 15;
      return (h >>> 0) / 4294967296;
    }

    /** Le nuage de la vue pour l'onglet 3D (spec 2026-09-27-vue-3d-design). */
    function nuage3d(emprise, budget, actifs) {
      if (gpu) return { raison: 'Nuage 3D indisponible quand tout le calcul est sur la carte graphique (&gpu).' };
      const e = { xmin: Math.round(emprise.xmin * 100), xmax: Math.round(emprise.xmax * 100), ymin: Math.round(emprise.ymin * 100), ymax: Math.round(emprise.ymax * 100) };
      const dedans = [...blocs].filter(([cle, b]) => (!actifs || actifs.has(cle)) && VUE_GRILLE.coupe(b.emprise, { emprise }));
      // Premier passage : compter, pour connaître le taux à tirer.
      let total = 0;
      for (const [, b] of dedans) {
        const p = b.points, [ox, oy] = b.origineCm;
        for (let i = 0; i < b.nbPoints; i++) {
          const x = p.xc[i] + ox, y = p.yc[i] + oy;
          if (x >= e.xmin && x < e.xmax && y >= e.ymin && y < e.ymax) total++;
        }
      }
      if (!total) return null;
      const taux = Math.min(1, budget / total);
      // Second passage : garder, dans des tableaux au plus juste.
      const cap = Math.min(total, Math.ceil(budget * 1.05) + 1000);
      let xs = new Int32Array(cap), ys = new Int32Array(cap), zs = new Int32Array(cap);
      let cls = new Uint8Array(cap), its = new Uint16Array(cap), n = 0;
      let zminCm = Infinity, zmaxCm = -Infinity;
      for (const [, b] of dedans) {
        const p = b.points, [ox, oy, oz] = b.origineCm;
        for (let i = 0; i < b.nbPoints; i++) {
          const x = p.xc[i] + ox, y = p.yc[i] + oy;
          if (x < e.xmin || x >= e.xmax || y < e.ymin || y >= e.ymax) continue;
          const z = p.zc[i] + oz;
          if (taux < 1 && hacher(x, y, z) >= taux) continue;
          if (n === xs.length) {   // tirage au-dessus de la réserve : on agrandit
            const agrandir = (t) => { const u = new t.constructor(t.length * 2); u.set(t); return u; };
            xs = agrandir(xs); ys = agrandir(ys); zs = agrandir(zs); cls = agrandir(cls); its = agrandir(its);
          }
          xs[n] = x; ys[n] = y; zs[n] = z; cls[n] = p.cls[i]; its[n] = p.intensite ? p.intensite[i] : 0;
          if (z < zminCm) zminCm = z; if (z > zmaxCm) zmaxCm = z;
          n++;
        }
      }
      const origine = [e.xmin / 100, e.ymin / 100, zminCm / 100];
      const X = new Float32Array(n), Y = new Float32Array(n), Z = new Float32Array(n), H = new Float32Array(n);
      const t = memoCouche && memoCouche.t;
      const compte = new Map();
      for (let i = 0; i < n; i++) {
        X[i] = (xs[i] - e.xmin) / 100; Y[i] = (ys[i] - e.ymin) / 100; Z[i] = (zs[i] - zminCm) / 100;
        compte.set(cls[i], (compte.get(cls[i]) || 0) + 1);
        if (t) {
          const cx = Math.floor((xs[i] / 100 - t.emprise.xmin) / t.pas), cy = Math.floor((ys[i] / 100 - t.emprise.ymin) / t.pas);
          if (cx >= 0 && cy >= 0 && cx < t.W && cy < t.H && t.valide[cy * t.W + cx]) {
            H[i] = zs[i] / 100 - (t.mnt[cy * t.W + cx] + t.origine[2]);
          }
        }
      }
      return {
        n, x: X, y: Y, z: Z, cls: cls.slice(0, n), intensite: its.slice(0, n), hauteur: H,
        origine, emprise: { ...emprise }, zmin: 0, zmax: (zmaxCm - zminCm) / 100,
        parClasse: [...compte].sort((a, b) => a[0] - b[0]),
      };
    }
```

- [ ] **Step 1: Shader**

```glsl
// edlFS : ombrage de profondeur (Boucheny 2009, comme Potree). Chaque pixel est
// assombri selon ce que ses huit voisins, à u_rayon pixels, ont de plus proche
// que lui, en log2 de la profondeur de vue ; le fond (profondeur 1) borde le
// nuage d'un trait sombre, qui détache sa silhouette.
#version 300 es
precision highp float;
uniform highp sampler2D u_couleur;
uniform highp sampler2D u_profondeur;
uniform vec2 u_taille;          // pixels
uniform float u_rayon;
uniform float u_force;
uniform float u_proche; uniform float u_loin;
out vec4 o;
float logProf(vec2 uv) {
  float d = texture(u_profondeur, uv).r;
  if (d >= 1.0) return 0.0;
  float z = 2.0 * u_proche * u_loin / (u_loin + u_proche - (2.0 * d - 1.0) * (u_loin - u_proche));
  return log2(z);
}
void main() {
  vec2 uv = gl_FragCoord.xy / u_taille;
  float d = texture(u_profondeur, uv).r;
  float c = logProf(uv);
  float somme = 0.0;
  for (int k = 0; k < 8; k++) {
    float a = float(k) * 0.78539816;
    float v = logProf(uv + vec2(cos(a), sin(a)) * u_rayon / u_taille);
    if (v != 0.0) somme += (c == 0.0) ? 100.0 : max(0.0, c - v);
  }
  float ombre = exp(-somme / 8.0 * 300.0 * u_force);
  vec4 couleur = texture(u_couleur, uv);
  o = vec4(couleur.rgb * ombre, 1.0);
  gl_FragDepth = d;
}
```
