# Détection des tracés — plan de travail

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un détecteur de tracés (chemins, routes, ruisseaux, sentes) sur le SVF de Scopus, noté contre la BD TOPO, puis branché dans la vue normale ; `sentiers.js` retiré.

**Architecture:** `src/traces.js` (fabrique sérialisable pour le worker) porte la découpe, la mesure et le détecteur ; `IGN.lineaire` récupère la BD TOPO ; `tools/banc-traces.js` enchaîne blocs COPC → SVF (`VUE_RELIEF`) → détection → mesure → rapport d'images. L'appli appelle la détection dans le worker du relief et dessine les tracés sur la carte.

**Tech Stack:** scripts classiques (file://), Node 20 `node --test`, laz-perf WASM, zlib pour les PNG du banc.

**Spec:** `docs/superpowers/specs/2026-09-27-traces-design.md`

## Global Constraints

- Aucun réseau de neurones ni apprentissage ; chaque étape explicable.
- Le détecteur ne lit que le SVF (et la validité des cases) ; l'IGN ne sert qu'à noter.
- Réglages en mètres ou en valeurs normalisées ; jamais d'évaluation sur une image réduite.
- Scripts classiques, pas de module ES ; toute fonction du worker ne ferme sur rien (`function fabriqueTraces()`).
- Cible : rappel ≥ 70 % et précision ≥ 50 % à T = 10 m sur `0536_6214` ; `0535_6214` ne s'effondre pas.
- Commits en français, avec les lignes d'attribution de la session.

## Review Focus

- Un tronçon IGN entièrement hors de la dalle, ou qui la traverse sans sommet dedans : la découpe doit garder la traversée.
- Une grille avec des cases NaN (sans sol) : la détection les ignore, ne trace rien dans un grand trou.
- Un tracé détecté sur le bord de la grille (la marge) : découpé sur l'emprise avant mesure.
- La vue qui change pendant une détection dans l'appli : les tracés d'une vue quittée ne s'affichent pas.
- Une vue trop large (pas > pas maximal) : le bouton le dit, rien ne tourne.

### Task 1 : découpe et mesure (`src/traces.js`)

**Files:** Create `src/traces.js`, `test/traces.test.js` ; Modify `index.html` (script après `vue-relief.js`).

**Produces:**
- `TRACES.decouper(lignes, emprise) → lignes` — `lignes` : tableau de polylignes `[[x, y], …]` en Lambert-93 ; rend les morceaux dans l'emprise (Liang–Barsky par segment, morceaux contigus recollés).
- `TRACES.longueur(lignes) → m`.
- `TRACES.mesurer(detectes, reference, emprise, tolerance, pas = 0.5) → { rappel, precision, longueurReference, longueurDetectee }` — les deux jeux découpés sur l'emprise, rastérisés à `pas`, transformée de distance exacte (Felzenszwalb) ; rappel = longueur de référence à ≤ tolérance d'un détecté / longueur de référence ; précision symétrique. Valeurs dans [0, 1] ; `NaN` si la longueur de référence est nulle.

- [ ] Tests (écrits d'abord, vus échouer) :
  - découpe : un segment qui traverse l'emprise sans sommet dedans est gardé sur sa traversée ; un segment dehors disparaît ; longueur d'un L découpé exacte à 1 cm ;
  - mesure : mêmes lignes → rappel 1, précision 1 ; décalage parallèle de 5 m → 1 et 1 à T = 10 m, 0 et 0 à T = 2 m ; référence + une ligne de trop détectée de même longueur → précision 0,5 ; détection vide → rappel 0, précision NaN.
- [ ] Implémentation, tests verts, `npm test` vert, commit « Traces : découpe et mesure ».

### Task 3 : le banc (`tools/banc-traces.js`)

**Files:** Create `tools/banc-traces.js`, `tools/natif.js` (sources dans le contexte principal), `tools/png.js` (encodeur PNG minimal, zlib) ; Modify `package.json` (`"banc-traces"`), `.gitignore` si besoin (`.tmp/` déjà ignoré).

**Consumes:** `TRACES.mesurer`, `TRACES.decouper`, `IGN.lineaire`, `COPC`, `DECODEUR.decoderBloc`, `VUE_RELIEF`, `VUE_GRILLE`.

Pour chaque dalle de `DALLES` (référence `0536_6214`, contrôle `0535_6214`) :
1. hiérarchie COPC, blocs dans `.tmp/banc-traces/<dalle>/<offset>.bin` (téléchargés une fois, 5 en vol) ;
2. décodage en centimètres, `VUE_RELIEF.creer({ moteur: 'cpu' })`, `ajouter` ;
3. SVF au pas `PAS` (0,5 m ; `--pas 1`) via `calculer(geo, 'svf')` ;
4. `TRACES.detecter(t, reglages)` sur la surface et la couche (la même interface que dans le worker, Task 5) ;
5. `IGN.lineaire` (cache JSON), `TRACES.mesurer` à 10 et 20 m ;
6. rapport : une ligne par dalle (rappel, précision, longueurs, durée), `rapport.json`, et `rapport.html` avec, par quart à pleine résolution, le SVF + détection (rouge) + IGN (bleu clair).

- [ ] Le banc tourne de bout en bout avec `detecter` qui rend `[]` : rappel 0 % sur les deux dalles — c'est le test qui échoue. Commit.

### Task 5 : le détecteur, première approche (filtre de lignes)

**Files:** Modify `src/traces.js`, `test/traces.test.js`.

**Produces:** `TRACES.detecter(t, reglages) → { lignes, stats }` où `t` est la surface de `VUE_RELIEF` (`W`, `H`, `pas`, `emprise`, `valide`) et `reglages.svf` la couche SVF (`Float32Array`, NaN hors données) ; `lignes` en Lambert-93. Étapes : normalisation du SVF (médiane locale), réponse de creux de la hessienne à largeurs 1–4 m (valeur propre positive dominante, normalisée), hystérésis, squelette, polylignes, raccordement des bouts alignés à < `raccordM`, filtres longueur ≥ `longueurMinM` et compacité.

- [ ] Tests synthétiques (écrits d'abord) : un trait sombre courbe de 2 m de large dans un bruit gaussien est retrouvé à 90 % de sa longueur à 2 m près ; une tache ronde de 6 m n'est pas un tracé ; un trait coupé par un trou NaN de 4 m est un seul tracé ; bruit seul → aucun tracé de plus de `longueurMinM`.
- [ ] Banc : noter rappel / précision sur les deux dalles, images à l'utilisateur. Commit avec les chiffres dans le message.
